Generated by `bench/report.py`; do not edit. Numbers are from one machine and compare tools on that machine only.

Machine: AMD Ryzen 9 9900X 12-Core Processor, 24 logical cores, Linux-6.18.60-1-lts-x86_64-with-glibc2.44, Python 3.13.18, go version go1.27.3-X:nodwarf5 linux/amd64. Other sessions used the machine during the runs (the load average at each run is in `run.log`).

Versions: beautifulsoup4 4.15.0, lxml 6.1.3, html2text 2025.4.15, inscriptis 2.7.7, resiliparse 2.0.1, selectolax 1.0.2, markitdown 0.1.9, trafilatura 2.3.1, htmd (crate) 0.2.2, html2text (crate) 0.14.4.

**Input:** 9,835 HTML pages, 1.45 GiB, the `text/html` 200 responses of the first 400 MB of one Common Crawl WARC file (CC-MAIN-2026-43), as served. Each tool reads every page in one long-lived process, the way a pipeline does, with one worker and with 24; the time of a page is the call alone, after its bytes are read. Wall time, CPU time and peak memory are of the whole process tree.
